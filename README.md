# Orion — condosorion.com

Site de location de l'immeuble **Orion**, 2485, rue Bélanger, Villeray (Montréal).
Site statique : aucun outil de construction, aucune dépendance. On ouvre `index.html` et c'est tout.

## Contenu

| Fichier | Rôle |
|---|---|
| `index.html` | Page d'accueil (photos, visites 3D, inclusions, espaces communs) |
| `plans-et-promotions.html` | Plans et loyers : encadré meublé, tableau des loyers, plans par type, visites 3D |
| `0005--310.jpg` … `0035--0005_1.jpg` | Photos des espaces |
| `202-01.jpg` … `202-19.jpg` | Galerie de l'unité 202 |
| `logo-orion.png`, `og-image.jpg`, `favicon*` | Logo, image de partage, icônes |
